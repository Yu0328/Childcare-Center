# 課程月計畫：每位幼兒各自一份，用「套用」複製（取代共用項目與指定新增）

取代 `2026-10-09-monthly-plan-designated-add-mode-design.md` 的指定新增模式，並取消 `2026-10-09-monthly-plan-child-only-items-design.md` 的「共用項目」。

## 為什麼改

老師常誤會「指定新增」：要先開開關、點名字是加選而不是切換、開著時共用項目又改不了，要記住的事太多。改成跟適性紀錄的「套用其他幼兒課程計畫」一樣的想法：**在誰的月曆上改，就只動到誰**；要讓別的幼兒照著排，就套用。

## 規則

- 月計畫裡每個項目都屬於一位幼兒（PlanSlotItem 一定帶 `childId`）。不再有共用項目。
- 任何兩位幼兒都能互相套用，不限年齡層。項目帶的指標代碼原樣複製（跟 指標所屬年齡層 切換選到較早指標一樣），放進目標幼兒自己年齡層的 PlanSlot（`plan.childTiers[目標]`，同週、同星期）。
- 套用＝**整個月取代**：目標幼兒這份月計畫原本的項目全部換成來源幼兒的。
- 複製：日期（週／星期）、指標代碼、活動名稱、指標內容。不複製：未達成、請假／其他活動代替（目標幼兒的新項目沒有 override）。

## 畫面

### 拿掉
- 「指定新增」開關、開啟時的提示、加選名字（紫底＋✓）、手機名字按鈕上的「＋2」、紫色邊框。點名字一律是切換幼兒。
- 月曆格子與編輯面板的「個別」標籤。
- 共用項目的鎖定（`lockedNow` 等）。

### 刪除確認
一律：確定要刪除王小明的「活動名稱」嗎？此操作無法復原。（不再有「同階段 N 位幼兒都會一起刪除」）

### 套用按鈕與視窗
- 月計畫編輯畫面上方加「套用其他幼兒月計畫」，手機顯示「套用」（`headerButtonLabel`），紫色，跟適性紀錄那顆同一種。套用的對象是目前顯示的幼兒。
- 視窗沿用 `copyCoursePlanPanel.js` 的版面：標題「套用其他幼兒月計畫」，單選列出這份月計畫裡其他**至少有一個項目**的幼兒「林小美（12 筆）」，按鈕「套用」「取消」。沒有可套用的幼兒時顯示「這份月計畫裡沒有其他已排課的幼兒。」
- 按「套用」後確認：「王小明目前的 8 筆會換成林小美的 12 筆，未達成、請假的勾選不會複製。確定要套用嗎？」目標幼兒是 0 筆時改成「要把林小美的 12 筆套用給王小明嗎？」
- 完成後重新整理月曆，停在目標幼兒。

## 資料

### 新函式（`src/domain/copyMonthlyPlan.js`）
- `findMonthlyPlanCopySources(plan, targetChildId, items)`：其他幼兒與各自筆數。
- `copyMonthlyPlan({ planId, targetChildId, sourceChildId })`：先複製後刪除（中斷時寧可多出重複，不會遺失），刪除走 `deletePlanSlotItem`（順便清掉 override）。同一位幼兒時不動作。

### 舊資料轉換（`splitSharedItems(planId)`，放在 `monthlyPlanDb.js`）
在 `loadEditorData` 一開始執行（Word 匯出也是從編輯畫面的資料來，所以一併涵蓋）。對每個**沒有 `childId`** 的項目：
- 給這份計畫裡 `childTiers` 等於該 slot 年齡層的每位幼兒各建一份，帶 `childId`。
- 新項目的 `uid` 用固定算法 `${共用項目uid}~${幼兒uid}`，兩台已登入的裝置各自轉換時產生同一筆記錄，同步後合而為一，不會重複。
- 該幼兒原本掛在共用項目上的 override 改指向新項目（`itemId` 更新，保留 uid）。
- 最後刪除共用項目。
- 沒有共用項目時什麼都不做，所以每次開都跑也沒關係；舊版裝置之後再加的共用項目，下次在新版打開時也會被轉換。

已知的過渡現象：還沒更新的舊版裝置會把轉換後的項目全部標成「個別」。等那台裝置自動更新後就會恢復正常，可以接受。

### 其他寫入 PlanSlotItem 的地方
| 位置 | 改動 |
|---|---|
| 編輯面板新增 | 一律帶 `childId: 目前幼兒` |
| `monthlyPlanImportPreviewView.js`（Word 匯入） | 每位幼兒各建一份；該幼兒的 override 掛在他自己那份上 |
| 預設活動（大團體活動／節氣） | 新增月計畫時每位幼兒各填一份；管理幼兒加入新幼兒時只幫新加入的幼兒填，其他內容由老師用「套用」複製 |
| `itemVisibleToChild` | 保留，讓舊版資料轉換前也能正常篩選；共用項目分支之後不會再產生 |
| 同步 `naturalKey`、備份、`deleteChildOnlyItemsForChild` | 不變 |

選指標時的達成狀況（已達成／未達成／還沒做過，以及依狀態列出同階段幼兒）保持不變。

## 操作說明

- 「安排一天的活動」：拿掉跟共用有關的說明，明確寫出只會加到目前這位幼兒。
- 「幫一位幼兒補課」：改成切換到該幼兒 → 打開補課那天 → 新增。不用開關。
- 新增「套用其他幼兒的月計畫」示範：排好小明 → 切換到小華 → 按「套用其他幼兒月計畫」／「套用」→ 選小明 → 確認 → 小華的月曆出現同樣的課。
- 影片：「課程月計畫」章節（電腦版和手機版各一個）旁邊加註「此段為舊版畫面，請參考下方文字說明」，章節清單和文字說明裡的「看影片的這一段」連結旁邊都要有。影片之後重新錄製時，再更新 `HELP_VIDEOS` 並拿掉這段註明。

## 測試

- `copyMonthlyPlan`：整個月取代、跨年齡層放到目標的 slot、override 不複製、目標原本的項目和 override 被清掉、來源不受影響、同一人時不動作。
- `splitSharedItems`：依年齡層每位幼兒一份、uid 是固定算法（跑兩次結果一樣）、override 跟著改指向、共用項目被刪、不同年齡層的幼兒不會拿到。
- 編輯畫面：沒有指定新增和個別標籤、新增只給目前幼兒、刪除確認文字、套用視窗（列表、無來源訊息、兩種確認文字）。
- Word 匯入：每位幼兒各一份，override 掛對。
- 通知：有月計畫時第一次跳出、按了之後不再出現、沒有月計畫時不跳。
- 用 `dist/TableC.html` 在 1400px 和 390px 寬實際操作截圖：舊資料打開後轉換結果正確、套用、通知。
