# 課程月計畫：指定新增模式（取代面板內的「適用幼兒」）

接續 `2026-10-09-monthly-plan-child-only-items-design.md`。資料（PlanSlotItem 的 `childId`）、「個別」標籤、Word 匯出、備份、同步、移除幼兒時的清理全部不變，只改「怎麼新增個別項目」。

## 為什麼改

原本的「適用幼兒」（同階段共用／僅限○○）放在新增表單最上面，老師填完指標、活動名稱按新增時已經不看上面，常常忘了切換，結果加給了同階段所有幼兒。老師常見的情境是請假一整週、要連續補好幾天，所以改成「開一次、連續新增」的模式，並讓模式在畫面上一直看得到。

## 用詞

| 位置 | 文字 |
|---|---|
| 月曆上方開關 | 指定新增 |
| 開啟時的提示（工具列） | 點姓名加選幼兒（沒有同階段其他幼兒時不顯示） |
| 開啟時的提示（面板最上方） | 新增項目只給王小明、林小美；共用項目暫停編輯、刪除。 |
| 面板新增按鈕 | 新增（不論模式開關都一樣） |
| 手機收合的名字按鈕 | 王小明 ▾；開啟模式且選了人時「王小明 ＋2 ▾」 |

## 行為

- 開關在幼兒名字那一排（`.monthly-plan-toolbar`），只有一位幼兒的計畫也會顯示。
- **開啟時**：
  - 目前幼兒的月曆和編輯面板換成紫色邊框（`--edit-accent`）。
  - 點**同階段**其他幼兒的名字＝選取／取消「同時新增」（紫底＋✓），不切換幼兒；不同階段的名字停用、變淡。
  - 選取在模式開著期間保留，連續新增不用重選。
  - 新增時目前幼兒＋每位被選的幼兒各建一份個別項目（各自獨立）。
  - 共用項目的「編輯」「×」隱藏，程式端也擋掉儲存與刪除；「未達成」「請假」照常可勾（本來就只影響這位幼兒）。
  - 切換開關不會清掉表單裡已打的字（就地更新，不重畫面板）。
- **關閉**：再按一次開關、或離開這個月計畫。關閉時清空選取。要切換幼兒必須先關閉（開啟時點名字是選人）。
- 面板內原本的「適用幼兒」與「同時新增給」移除。

## 版面

- 電腦：名字一排（太多自動換行），開關與提示接在後面。
- 手機（≤640px）：名字收在左邊「王小明 ▾」按鈕，右邊是開關，平常只佔一行；點按鈕展開成每行 3 個的等寬格子，點名字切換幼兒並收起。開啟模式時自動展開；收起時不顯示「點姓名加選幼兒」（看不到名字），改由按鈕上的「＋2」提示已選人數。

## 操作說明

「幫一位幼兒補課」示範改為：勾「指定新增」→（可略過）點同學名字 → 打開補課那天 → 選指標按「新增」→ 兩人格子各多一堂「個別」。「安排一天的活動」的按鈕文字改為「新增」。

## 測試

編輯畫面：關閉時新增共用項目、按鈕文字為「新增」；開啟後新增個別項目並保留已打的字、提示文字；點同階段名字選取（不切換）、不同階段停用、手機按鈕「＋1」；兩人各一份、刪一份另一份還在；再點取消選取、關閉後清空且名字恢復切換；開啟時共用項目的儲存與刪除無效。實機以 14 位假幼兒在 1400px 與 390px 寬截圖檢查。
