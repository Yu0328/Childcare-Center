# 課程月計畫編輯畫面排版修正

日期：2026-09-26

用假資料在 1440／1024／390 三種寬度實測後發現的排版問題，這次修其中五項（另外四項——手機週五落單、替代文字黏在劃線文字後、週一二五格子留白、B表／7-12個月兩種稱呼——暫不處理）。

## 問題與修法

1. **點格子後整個月曆變窄重排**：原本閒置時右欄收起、月曆全寬，點了格子才長出右欄，月曆每格重新換行、畫面跳動。
   → 寬螢幕（≥1280px）右欄永遠保留，閒置時放一行淡色提示。
2. **1024 左右寬度幾乎無法閱讀**：右欄至少 340px，剩下的寬度塞 5 欄，一行只剩 3～4 字。
   → 641～1279px 右欄改成跳出視窗（沿用手機那套），月曆保持全寬；這個寬度沒有「＋」浮動按鈕，所以單擊格子就直接開視窗（手機維持雙擊）。
   跳出視窗的置中樣式原本只寫在手機寬度的規則裡，改成依「視窗是否以跳出方式開啟」（`:modal`）判斷，一般桌機內嵌的表單不受影響。
5. **切換幼兒後編輯區還是上一位的**：切換只藏月曆，沒清掉已選格子，勾選會記到前一位身上。
   → 切換時清掉選取、編輯區回到提示、收起「＋」。
6. **項目標題被「編輯／×」擋到**：標題右側只預留一顆按鈕的寬度，這裡有兩顆。
   → 月計畫編輯區的項目標題右側多留空間。
9. **提示文字位置**：原本閒置提示排在幼兒切換鈕上方，不顯眼。
   → 隨第 1 點一起移到右欄。

## 寬度分界

1280px 寫在兩處，需同步：`monthlyPlanEditorView.js` 的 `PANEL_POPUP_QUERY` 與 `styles.css` 月計畫段落的 media query。
