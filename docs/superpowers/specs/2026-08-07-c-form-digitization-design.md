# C表數位化系統 — 設計文件

日期：2026-08-07

## 背景與問題

親子館托育人員需為每位幼兒填寫「嬰幼兒發展評量紀錄表（C表）」。此表格內容依《托嬰中心嬰帅兒適性發展活動實務指引》第貳章的標準指標而定（5 個月齡階段 × 5 大發展領域，共 137 項指標）。

目前用 Word 範本人工填寫，痛點在於：

- 每次新增一位孩子的表格，都要在 Word 裡重新輸入/複製整套指標代碼與活動描述文字，容易漏改、貼錯儲存格
- 需要老師自行判斷孩子目前月齡對應到哪個階段（Ⅰ~Ⅴ），並手動找出該階段的完整指標清單
- 表格預留固定空白列數給每個指標記錄多次觀察，格式僵硬、不好對照填寫

## 範圍

本文件僅涵蓋**第一階段：C表數位化**（幼兒觀察紀錄的建立、填寫、儲存、匯出）。

**第二階段（家長版月報表產生器）不在本次範圍內**，將於第一階段完成並實際使用驗證後另行設計。第二階段會讀取本階段建立的資料（已達成指標清單）作為輸入來源，因此本階段的資料結構需保持乾淨、結構化，以利未來擴充。

## 技術形式

單一 HTML 檔案的本機網頁應用，雙擊即可用瀏覽器開啟（Windows/Mac 通用，不需安裝任何額外軟體或執行環境）。

- 畫面與互動：HTML/CSS/JavaScript
- 資料儲存：瀏覽器 IndexedDB（本機儲存，不連網）
- Word 匯出：使用 JS docx 產生函式庫（`docx` npm package 打包進頁面內，離線可用），依程式邏輯直接組裝 OOXML 文件，格式固定、可重複產生，不受瀏覽器渲染影響
- 不依賴任何後端伺服器、不需要網路連線

## 資料模型

**幼兒 Child**
- id
- 姓名
- 出生年月日

**評量表 AssessmentForm**
- id
- childId（所屬幼兒）
- tier（月齡階段代碼，Ⅰ~Ⅴ 之一）
- period（紀錄年月，如「115年03月」）
- createdAt

一位幼兒可有多份評量表：每份對應「一個月齡階段＋一個紀錄年月」，同一階段常會橫跨數個月份，因此同一階段底下可能有多份表（例如Ⅳ階段有115年01月、02月、03月三份）。

**觀察紀錄項目 ObservationEntry**
- id
- formId（所屬評量表）
- indicatorCode（指標代碼，如 Ⅳ-1-1）
- date（觀察日期）
- achieved（是否達成，布林值，對應原表的「○」記號）
- note（觀察敘述文字）

同一指標代碼下可有多筆觀察紀錄項目，由老師自行新增，無固定筆數上限或預留空白列。

**指標參考庫 IndicatorReference**（內建靜態資料，不需老師輸入）
- tier（月齡階段）
- domain（發展領域，1~5）
- subdomain（領域範疇）
- code（指標代碼）
- description（發展活動描述文字）

資料來源：《托嬰中心嬰帅兒適性發展活動實務指引》第貳章 表二-7（0-2歲嬰帅兒發展要項與適性活動綱要總表），涵蓋全部 5 階段 × 5 領域共 137 項指標，於實作階段整理為結構化 JSON 內建於程式中。

## 月齡對照邏輯

新增評量表時：

1. 系統以「今天日期－該幼兒出生日期」自動計算月齡，並預先選取對應的階段（Ⅰ~Ⅴ）
2. 老師可手動切換為其他階段——用於老師事後補寫已跨過該月齡階段的觀察紀錄時，仍能對應到正確階段的指標
3. 老師另外選擇這份表所屬的紀錄年月（如「115年03月」），預設可帶入目前年月，但可自由更改

一旦評量表建立後，其所屬階段與紀錄年月固定，不會因為之後開啟頁面時「今天日期」改變而自動變動。

## 操作流程

1. **幼兒列表**：顯示所有已建立的幼兒，可新增幼兒（輸入姓名、出生日期）
2. 點選某位幼兒 → 進入該幼兒的**評量表清單**，依紀錄年月排序，顯示每份表所屬的階段與年月，可新增一份新表（選擇階段＋紀錄年月，階段預設依當下月齡計算但可手動覆蓋）
3. 點選某份評量表後，畫面依 5 大發展領域分區塊，列出該表所屬階段的全部指標（代碼＋活動描述，唯讀，不用手動輸入）
4. 每個指標下方顯示已新增的觀察紀錄（日期、達成勾選、敘述），並有「新增觀察紀錄」按鈕，點擊後可填入日期、勾選是否達成、輸入敘述文字；已新增的紀錄可編輯或刪除
5. 所有輸入即時自動儲存，不需手動按「儲存」

## 資料儲存與備份

- 平時資料存在瀏覽器本機 IndexedDB
- 提供「匯出備份」功能，將全部資料匯出成一個檔案下載，供老師定期備份或搬移到其他電腦
- 提供「匯入備份」功能，可讀取先前匯出的備份檔案還原資料

## Word 匯出

- 針對指定的一份評量表（某幼兒＋某階段），依現有 C表範例的表格格式（欄位：發展領域、領域範疇、指標項次/發展活動、實施記錄）產生 .docx 檔下載
- 列數依老師實際填寫的觀察紀錄筆數動態產生，指標若尚無任何紀錄則產生一列空白（維持原表格「每個指標至少一列」的閱讀習慣）
- 開發時需將實際匯出檔案與現有 C表範例逐項比對表格結構、欄位、字型，確認一致後才視為完成

## 非目標（本階段不做）

- 家長版月報表產生（第二階段）
- 多人協作／雲端同步
- 照片上傳與管理（第二階段才需要）
- 其他表單（A表、B表等）的數位化

## 驗收方式

- 建立測試幼兒（沿用「陳小安」範例的出生日期與階段Ⅳ），依範例 C表 內容輸入觀察紀錄，比對匯出的 .docx 檔案與原始範例檔案的表格結構、文字內容是否一致
- 確認月齡自動對應與手動覆蓋階段功能皆正確運作
- 確認同一幼兒、同一階段可建立多份不同紀錄年月的評量表，彼此資料互不影響
- 確認備份匯出/匯入後資料完整不遺失
