# 介面美觀調整 — 設計

來自全面檢查時找到的畫面問題（A–I），逐項對應如下。只改顯示，不動資料與 Word 匯出入。

- **A. 手機標題列太佔空間**：「匯出備份／匯入備份」收進一個「備份 ▾」小選單（`details.backup-menu`）。離線檔的標題和「備份」同一行；網頁版訪客模式的問候語、Google 登入、備份同一行，狀態列沒有文字時不佔空間。選單按下匯出／選好匯入檔後自動收起，點選單外也收起（`wireBackupControls`）。鎖定前按鈕依然停用，原本的密碼保護不變。
- **B. 日期是西元格式**：畫面上的日期改成民國（`toRocDate`，115/04/02），包含總表、課程計畫表、兩種匯入預覽。輸入欄位和存檔的值不變。電腦版總表五欄很窄，只顯示月/日（和紙本一樣），年份已在標題的期間裡。
- **C. ○△ 太小、顏色一樣**：標記放大；○ 綠色、△ 橘色。課程計畫表的狀態改成小圓角標籤（已發展綠、發展中橘、請假／更換課程紅）。
- **D. 手機巢狀內距太多**：640px 以下縮小頁面、領域卡、指標卡、紀錄列的左右內距。
- **E. 適性紀錄分頁在手機斷成兩行不整齊**：手機改成整齊的 2×2 分頁塊，選中的那格白底。
- **F. 標題不一致**：總表和適性紀錄的標題在手機一律分兩行：「姓名　階段」一行、期間一行（較小、灰色）；電腦版維持一行。
- **G. 總表列表分不出同階段同期間的表**：每一列加上「N 筆紀錄」；同一期間內依階段排序，同階段的排在一起。
- **H. 電腦版月計畫右側提示欄佔太多寬度**：還沒選日期（也沒開管理幼兒）時，右欄收成日曆上方一條「點選日期格子開始規劃」，日曆佔滿整個寬度；選了日期才出現右欄。
- **I. 電腦版課程計畫表的空洞**：領域卡改成上下排列，展開的卡片裡的活動分成多欄，不再一開一關並排留下大塊空白。

## 順帶修正

- 手機寬度畫出來的頁面再拉寬到電腦寬度時（視窗縮放、平板轉向），右下角「＋」按鈕會變成沒有樣式的巨大「＋」。電腦寬度一律隱藏這個按鈕。
- 適性紀錄匯入預覽漏了「更換課程」的標示。
- 幼兒列表的出生日期也改成民國格式，和其他畫面一致。
- 手機登入後，「首次同步中…」的提示縮短成「首次同步中，請稍候…」，小手機上不再擠成三行。
- 手機上的各種列表（幼兒、總表、適性紀錄、月計畫）不再是框內捲動，整頁一起往下滑；電腦版維持有固定高度的框框，和旁邊的新增欄位對齊。
- 手機登入後的標題列：「立即同步／登出」移到問候語同一行，狀態文字自己一行（沒有文字時不佔空間），和訪客模式的排法一致；電腦版仍是一行，按鈕固定在最右邊。

## 第二輪（好讀、好操作、整齊）

- **J. 點一下就編輯**：總表的觀察紀錄與備註、適性紀錄的課程計畫項目與實施紀錄、發展紀錄、行為觀察、點滴分享，直接點那一筆就打開（再點一次收起）編輯表單，畫面上不再顯示「編輯」按鈕；「×」刪除保留不變。
  - 「編輯」按鈕仍留在頁面裡但看不見，用鍵盤（Tab）移到它時才出現，讓不用滑鼠的人一樣能編輯；原本的測試也照舊點它。
  - 共用一個 `wireRowClickEdit(container)`（`src/ui/rowClickEdit.js`）：可點的範圍標 `data-click-edit`，按鈕標 `data-row-edit`。巢狀時（課程計畫項目裡的實施紀錄）以最內層為準。點到按鈕、輸入欄位、連結、打開中的編輯表單，或正在選取文字時，不觸發。
  - 可點的範圍在電腦上滑過會微微變色、游標變手指，讓人知道可以點。
- **K. 月計畫一次看一位幼兒**：月計畫有兩位以上幼兒時，日曆上方出現一排幼兒名字，點名字切換，一次只顯示一位的日曆；手機和電腦都一樣。重新整理畫面（例如管理幼兒後）仍停在同一位；那位被移出計畫時回到第一位。匯出 Word 不受影響，照樣包含全部幼兒。
- **L. 新增表單的小錯誤**：勾選框不再被長說明擠小（`flex: none`）；「已發展／發展中」選項的 ○△ 改成和總表一樣的綠色／橘色符號，放在文字前面（總表和課程計畫兩處的選項都一樣）。
