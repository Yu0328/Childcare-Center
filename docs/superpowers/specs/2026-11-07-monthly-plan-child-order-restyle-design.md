# 月計畫「管理幼兒」與排順序：樣式調整

接續 `2026-11-07-monthly-plan-child-order-design.md`。使用者覺得原本的畫面不好看：「排順序」按鈕和「幼兒」沒有對齊、排序畫面分兩欄看不出順序、點過和沒點過差別太小、標題和說明對齊方式不一致。只改樣式和排序清單的排列方式，行為（完成／取消／儲存、關掉視窗回原順序）不變。

## 考慮過的做法

- **A（採用）保留膠囊，只修毛病**：打勾畫面不變，排序畫面改成一行一個。
- B 整個換成清單（打勾也一行一個、排序分「已排好／還沒點」兩區）：使用者看過示意圖後選 A。

## 設計

打勾畫面：
- 膠囊不變。「排順序」改成淡藍底（`--brand-tint` 底、`--brand-dark` 字）、前面加「⇅」，和「幼兒」同一行、垂直置中、靠右。

排序畫面：
- 標題「排順序」，底下灰字一行「依序點選幼兒」（不再有「沒點到的…」那句）。標題和說明同一種對齊（照 `panel-form__title` 現有的置中，說明也置中）——實作者照截圖讓兩者一致即可。
- 單欄，一行一個，由上往下就是順序。點過的照點的先後排在上面，沒點的照原順序排在下面（即畫面順序 = `applyTapOrder(現有順序, tapped)`）。
- 點過：左邊實心藍圈（`--brand` 底、白色數字 1、2、3…，不用 ①），整列淡藍底加藍框。
- 沒點：左邊灰色虛線圈，整列白底灰框。
- 再點一次取消，回到下面，號碼往前補。

按鈕：維持全系統慣例，主按鈕（完成／儲存）在左、取消在右（示意圖是相反，使用者同意照慣例）。

## 留給實作者

- 圓圈大小、列高、間距照示意圖（列約 44px 高、圓 24px）與現有 `panel-form` 風格。
- 手機（390px）與電腦都要截圖確認。
